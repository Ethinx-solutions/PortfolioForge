## Reusable Framework for Founder-Led Product Launches

**Version:** 1.0  
**Created:** January 30, 2026  
**Status:** Production Ready  
**Use Case:** Generate platform-specific launch plans, founder profiles, and brand-aligned marketing content

## 🎯 SKILL PURPOSE

This skill encapsulates the complete logic for generating founder-led product launches with:

- **4-week blitzkrieg execution plans** (from zero to $50K MRR)
- **Platform-specific founder profiles** (LinkedIn, Instagram, Facebook)
- **Brand-aligned marketing content** (carousels, email sequences, social templates)
- **Gamification campaigns** (T-Dog "Find" mechanics, leaderboards, rewards)
- **Marketing automation workflows** (Make.com, ManyChat AI)
- **Community building strategies** (Discord, email, social engagement)

---

## 🔧 HOW TO USE THIS SKILL

### **Step 1: Gather Founder Information**

Collect the following from the founder/user:

```
Founder Name: [Name]
Product Name: [Product]
Tagline: [Core message]
Target Audience: [Who they serve]
Primary Goal: [Revenue target, user acquisition, etc.]
Timeline: [4 weeks, 8 weeks, custom]
Budget: [Marketing budget]
Brand Colors: [Primary, Accent]
Mascot/Character: [Optional visual identity]
```

### **Step 2: Generate Master Launch Manifest**

Create a comprehensive manifest including:

1. **Executive Summary** — Mission, targets, timeline
2. **System Architecture** — Core components and features
3. **4-Week Blitzkrieg Plan** — Week-by-week execution
4. **Founder Brand Identity** — Positioning, values, tagline
5. **Platform-Specific Profiles** — LinkedIn, Instagram, Facebook
6. **Marketing Automation** — Email sequences, chatbot flows
7. **Gamification Campaign** — Engagement mechanics, rewards
8. **Deliverables Checklist** — Week-by-week milestones
9. **Success Metrics** — KPIs and measurement framework
10. **Month 2+ Expansion** — Scaling strategy

### **Step 3: Create Platform-Specific Content**

Generate content for each platform:

**LinkedIn:**
- Headline (120 characters)
- About section (2,600 characters)
- Featured content (4-5 items)
- Content pillars (3 topics, weekly)

**Instagram:**
- Bio (150 characters)
- Profile picture (visual identity)
- Highlights (5-6 categories)
- Content strategy (Reels, carousels, stories)

**Facebook:**
- About section
- Cover photo
- Content strategy
- Community group setup

### **Step 4: Design Gamification Campaign**

Create engagement mechanics:

1. **Hook** — What's the challenge/game?
2. **Mechanics** — How does it work?
3. **Rewards** — What do users get?
4. **Leaderboard** — How do we track winners?
5. **Cadence** — Weekly/monthly/ongoing?

### **Step 5: Build Marketing Automation**

Design workflows for:

1. **Email Sequences** — Triggers, timing, copy
2. **Chatbot Flows** — Conversation paths, lead capture
3. **Social Scheduling** — Posting calendar, content mix
4. **Paid Ads** — Targeting, creative, landing pages

### **Step 6: Package as Master Manifest**

Consolidate all outputs into single document:

```
LAUNCH_MANIFEST.md
├── Executive Summary
├── System Architecture
├── 4-Week Blitzkrieg Plan
├── Founder Brand Identity
├── Platform-Specific Profiles
├── Marketing Automation
├── Gamification Campaign
├── Deliverables Checklist
├── Success Metrics
└── Month 2+ Expansion
```

## 🎯 GAMIFICATION MECHANICS

### **T-Dog "Find" Campaign Template**

**Hook:** "Can you find T-Dog? 👀 Swipe through all 5 slides and type 'T-Dog' in the comments if you spot him!"

**Mechanics:**
1. Post carousel with hidden mascot
2. Users scroll looking for mascot
3. Users comment mascot name
4. You send mystery reward

**Rewards (3 Tiers):**
- Tier 1: Digital assets (stickers, wallpapers, roles)
- Tier 2: Engagement rewards (trial extension, coaching, merchandise)
- Tier 3: Monthly grand prize (cash, premium access, NFT)

**Leaderboard:**
- Track top finders
- Share weekly updates
- Feature in newsletter
- Monthly winner announcement

## 💡 BEST PRACTICES

### **Founder Positioning**

1. **Be Specific** — Not "entrepreneur," but "systems architect" or "revenue-first founder"
2. **Show Proof** — Real metrics, real results, real journey
3. **Build Community** — Celebrate wins, share learnings, create belonging
4. **Automate Everything** — Zero manual work where possible
5. **Move Fast** — Ship > perfect, iterate based on feedback

### **Content Creation**

1. **Hook First** — Grab attention in first sentence/image
2. **Provide Value** — Every post should teach or inspire
3. **Clear CTA** — Always tell people what to do next
4. **Consistent Branding** — Colors, fonts, tone across all platforms
5. **Authentic Voice** — Sound like a real person, not a corporation

### **Community Building**

1. **Respond to Everyone** — First 2 hours are critical
2. **Celebrate Wins** — Feature user success stories
3. **Create Inside Jokes** — Build tribal identity (T-Dog, catchphrases)
4. **Provide Exclusive Access** — Discord, early features, private calls
5. **Ask for Feedback** — Make community feel heard and valued
